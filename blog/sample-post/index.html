Hello, blog — sample post

May 30, 2026

Welcome to the blog. This is a simple static post served from GitHub Pages. To create a new post, copy /blog/template.html into a new folder (for example /blog/my-new-post/index.html) and replace the placeholders with your content.

Why this approach?

It's lightweight, works offline, and is compatible with GitHub Pages. If you want automation later, we can add a tiny script to generate the index from your post folders.
